# CLAUDE.md / AGENTS.md -- logging rules (required by the course)

For every interaction in this repository:
1. Append an entry to llm_log/LOG.md containing: date and time,
   team member, tool and model, the user's prompt (verbatim),
   your full response, and every file you created or modified
   (with line ranges).
2. Never edit or delete existing entries in llm_log/.
3. Commit the log update together with any code changes.
